# 🌱 Web Performance Metrics

> **Status:** Seed (Ide Mentah)  
> **Dibuat:** 2026-08-20  

## Metrik Utama Core Web Vitals
1. **LCP (Largest Contentful Paint)**: Waktu yang dibutuhkan elemen terbesar untuk dirender (< 2.5s).
2. **INP (Interaction to Next Paint)**: Responsivitas UI saat pengguna melakukan klik/interaksi (< 200ms).
3. **CLS (Cumulative Layout Shift)**: Pergeseran elemen layout yang tidak disengaja (< 0.1).
