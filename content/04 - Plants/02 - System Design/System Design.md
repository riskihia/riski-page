# 🏛️ System Design & Architecture

> **Status:** Category Index (Evergreen)  
> **Deskripsi:** Pustaka konsep arsitektur sistem berskala besar, sistem terdistribusi, dan desain infrastruktur perangkat lunak.

## 🗺️ Sub-Domain Pengetahuan
1. **Monolith vs Microservices Architecture**: Kapan harus memilih arsitektur terdistribusi vs monolithic.
2. **Event-Driven Architecture (EDA)**: Penggunaan Message Queue (Kafka, RabbitMQ, Redis Pub/Sub).
3. **High Availability & Fault Tolerance**: Load Balancing, Circuit Breaker Pattern, Rate Limiting, & Redundansi.
4. **Data Consistency**: CAP Theorem, BASE vs ACID, & Distributed Transactions (Saga Pattern).
