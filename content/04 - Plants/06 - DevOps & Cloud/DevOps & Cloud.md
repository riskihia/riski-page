# ☁️ DevOps, Cloud & Containerization

> **Status:** Category Index (Evergreen)  
> **Deskripsi:** Otomatisasi alur CI/CD, manajemen infrastruktur sebagai kode, kontainerisasi, dan deployment cloud.

## 🗺️ Sub-Domain Pengetahuan
1. **Containerization (Docker)**: Multi-stage builds, Docker Compose, Image Optimization.
2. **Orchestration (Kubernetes)**: Pods, Services, Ingress, Helm Charts, & Autoscaling.
3. **CI/CD Pipelines**: GitHub Actions, Automated Testing, Deployment Workflows.
4. **Infrastructure as Code (IaC)**: Terraform, Ansible, & Cloud Architecture (AWS, Cloudflare Pages).
