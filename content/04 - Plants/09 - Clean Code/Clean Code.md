# 🧹 Clean Code & Refactoring Practices

> **Status:** Category Index (Evergreen)  
> **Deskripsi:** Prinsip penulisan kode yang mudah dibaca, dikembangkan, diuji, dan dipelihara.

## 🗺️ Sub-Domain Pengetahuan
1. **SOLID Principles**: Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, Dependency Inversion.
2. **Test-Driven Development (TDD)**: Red-Green-Refactor Cycle, Unit Testing, Integration Testing, & Mocking.
3. **Refactoring Code Smells**: Menghilangkan Duplikasi (DRY), Long Method, Large Class, & Complex Conditionals.
4. **Design Patterns (GoF)**: Creational, Structural, & Behavioral Design Patterns.
